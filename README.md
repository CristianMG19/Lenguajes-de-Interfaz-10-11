## Organización del repositorio

- Cada práctica se guarda en su carpeta correspondiente.
- Las subprácticas **4.1**, **5.1** y **6.1** se ubican en la carpeta de su práctica principal.
- El archivo `README.md` se coloca en la raíz del repositorio.
- Los nombres de carpetas y archivos deben coincidir con las rutas del índice para que los enlaces funcionen.

## Ejecución

Para compilar y ejecutar los programas, es necesario contar con un entorno de desarrollo configurado para **ensamblador MASM e Irvine32**, como Visual Studio 2022. Abra el código fuente de la práctica correspondiente en un proyecto con dicha configuración y ejecútelo.
